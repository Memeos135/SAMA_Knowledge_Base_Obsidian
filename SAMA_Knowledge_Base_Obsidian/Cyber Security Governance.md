# Cyber Security Governance

## Connections

### [[Board of Directors]] — `references` [EXTRACTED]
- **What this link tells you:** When determining accountability for cyber security compliance, identify the board as the apex of the governance structure: the Framework places ultimate responsibility with the board and permits delegation to a cyber security committee, but the governance structure itself must be board-endorsed. This means a compliance or legal reviewer cannot treat committee delegation as a transfer of accountability — the board's endorsement and ultimate responsibility remain the anchor. Check that the governance structure, committee charter and mandate are demonstrably board-approved, since a governance regime lacking board endorsement is non-compliant regardless of how the committee operates.
- **Grounding — this node (Page 13 / 3.1.1):** "A cyber security governance structure should be defined and implemented, and should be endorsed by the board"
- **Grounding — related node (Page 13 / 3.1):** "The ultimate responsibility for cyber security rests with the board ... can delegate its cyber security responsibilities to a cyber security committee"

### [[Chief Information Security Officer (CISO)]] — `references` [EXTRACTED]
- **What this link tells you:** When mapping accountability under the SAMA Cyber Security Framework, treat the CISO role as an integral component of the governance regime rather than a standalone technical post. The Framework defines the cyber security function as headed by a CISO, independent of IT, reporting directly to the CEO/managing director, and places it within governance provisions where the Board holds ultimate responsibility. For a compliance assessment you would check that the reporting-line independence and Board oversight are demonstrably in place, since a CISO buried under IT would breach the governance control considerations.
- **Grounding — this node (Page 15):** "The Board of Directors has the ultimate responsibility for cyber security"
- **Grounding — related node (Page 48):** "A function, independent from the information technology function, that is headed by a CISO and that reports directly to the CEO/managing director"

### [[Cyber Security Committee]] — `references` [EXTRACTED]
- **What this link tells you:** When reviewing escalation and risk-acceptance decisions, note that the Cyber Security Committee is a governance body whose sign-offs carry regulatory weight, not merely an internal forum. The Framework's risk-acceptance provisions require accepted risks to be reported to the cyber security committee and to not contradict SAMA regulations, situating the committee within the governance structure. In a compliance check you would verify that risk acceptances above defined limits actually reached the committee and remained within risk appetite, because unreported acceptances would be a governance-control failure.
- **Grounding — this node (Page 21):** "the accepted cyber security risk does not contradict SAMA regulations"
- **Grounding — related node (Page 21):** "the accepted cyber security risk is within the risk appetite and is reported to the cyber security committee"

### [[Cyber Security Leadership and Governance]] — `references` [EXTRACTED]
- **What this link tells you:** When mapping the Framework's structure, read 'Cyber Security Governance' and 'Cyber Security Leadership and Governance' as the same governance domain that anchors board and senior-management accountability. The Framework places ultimate responsibility for cyber security on the Board of Directors and requires that responsibilities be defined throughout the organization. Conclude that governance obligations sit at the top of the control hierarchy, so audits should trace whether board-level intent, roles and responsibilities are documented before evaluating downstream technical controls.
- **Grounding — this node (Page 15 / 3.1.4):** "The Board of Directors has the ultimate responsibility for cyber security"
- **Grounding — related node (Page 15 / 3.1.4 Principle):** "Responsibilities to implement, maintain, support and promote cyber security should be defined throughout the Member Organization."
