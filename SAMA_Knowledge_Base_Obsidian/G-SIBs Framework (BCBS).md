# G-SIBs Framework (BCBS)

## Connections

### [[D-SIB Assessment Methodology]] — `references` [EXTRACTED]
- **What this link tells you:** When interpreting SAMA's D-SIB methodology, treat the BCBS G-SIB framework as its source and benchmark: SAMA states its approach 'is consistent with the BCBS D-SIB assessment methodology,' which the BCBS itself derived by extending the G-SIB rules text to domestic banks. This means the BCBS standard is a legitimate interpretive aid where SAMA's text is silent or ambiguous. For a compliance decision, however, note that SAMA calibrated indicators to the Saudi banking system — so the KSA methodology and thresholds govern, and BCBS text informs but does not override the domestic rule.
- **Grounding — this node (Page 4, para 1):** "The Basel Committee on Banking Supervision (BCBS) ... issued the rules text on the assessment methodology for global systemically important banks (G-SIBs)"
- **Grounding — related node (Page 4, para 3):** "consistent with the BCBS D-SIB assessment methodology ... calibrated to reflect the different aspects and operational dynamics of the Saudi Arabian Banking System"
