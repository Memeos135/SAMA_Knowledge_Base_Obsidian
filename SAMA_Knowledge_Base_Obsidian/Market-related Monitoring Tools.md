# Market-related Monitoring Tools

## Connections

### [[Liquidity Monitoring Tools]] — `references` [EXTRACTED]
- **What this link tells you:** When mapping the full set of liquidity-monitoring obligations, recognise that market-related monitoring tools are the fifth prescribed metric within the same Part 2 framework, not a distinct regime. Paragraph 176 lists them (item V) as a cornerstone metric supervisors use to assess a bank's liquidity risk, drawing on high-frequency market, financial-sector and bank-specific data as early-warning indicators. Conclude that this metric supplements the maturity-mismatch, funding-concentration, unencumbered-asset and currency metrics; do not treat market-data monitoring as external to the LCR supervisory package.
- **Grounding — this node (Page 52 / para 214):** "High frequency market data with little or no time lag can be used as early warning indicators in monitoring potential liquidity difficulties at banks."
- **Grounding — related node (Page 46 / para 176):** "The metrics discussed in this section include the following: ... V. Market-related monitoring tools"
