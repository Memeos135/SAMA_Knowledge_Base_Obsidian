# Financial Inclusion

## Connections

### [[Branch Network Policy]] — `conceptually_related_to` [EXTRACTED]
- **What this link tells you:** When drafting or reviewing a Branch Network Policy, treat financial inclusion as a required content element of the Policy itself, not a separate obligation. The same Regulation both mandates the Policy and prescribes that it cover the bank's approach to promoting financial inclusion and serving priority areas as part of CSR, which SAMA then reviews before granting no-objection. The practical consequence: assessing Policy completeness and assessing inclusion commitments are the same exercise, so a compliance check of one should confirm the other.
- **Grounding — this node (Page 7 / Sec 5.1(c)):** "Bank's approach towards promoting financial inclusion and increasing outreach of financial services"
- **Grounding — related node (Page 7 / Sec 5.1(h)):** "Plans for serving customers in priority areas as a part of corporate social responsibility (CSR)."

### [[Regulation on Branch Network]] — `references` [EXTRACTED]
- **What this link tells you:** When evaluating whether a bank's branch decisions comply, understand that promoting financial inclusion is a stated regulatory objective that SAMA actively reviews, not aspirational language. The Regulation lists 'promoting financial inclusion' among its objectives and requires the Branch Network Policy to set out the bank's approach to it, and SAMA weighs outreach measures when granting its no-objection. Conclude that a Policy silent on inclusion/priority-area outreach risks SAMA rejection, so this element should be checked substantively rather than treated as boilerplate.
- **Grounding — this node (Page 7 / Sec 5.1(c)):** "Bank's approach towards promoting financial inclusion and increasing outreach of financial services"
- **Grounding — related node (Page 6 / Sec 3(a)):** "Promoting financial inclusion and increasing outreach of financial services to the priority areas"
