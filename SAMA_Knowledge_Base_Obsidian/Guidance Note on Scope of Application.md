# Guidance Note on Scope of Application

## Connections

### [[Basel II Circular BCS 290 (June 2006)]] — `cites` [EXTRACTED]
- **What this link tells you:** When establishing the lineage and continuity of SAMA's scope-of-application policy, note that the Scope Guidance Note cites Circular BCS290 (June 2006) as the origin of the standalone-and-consolidated application requirement and states the scope has been unchanged since. The 'cites' link matters because it tells you the current scope rules are not a new departure but a continuation of the Basel II Detailed Guidance Document, and prudential-return requirements are aligned to that same scope. For a decision, you would treat BCS290 as the historical anchor but rely on the current Guidance Note text for the operative perimeter, checking whether any later circular superseded it.
- **Grounding — this node (Page 3):** "The scope remains unchanged since the issuance of Basel II –Detailed Guidance Document relating to Pillar 1 issued by SAMA in 2006"
- **Grounding — related node (Page 3):** "Circular No.BCS290 dated June 2006, all local banks were required to apply the SAMA's Basel requirements on a standalone and consolidated basis"

### [[SAMA Basel Framework]] — `references` [EXTRACTED]
- **What this link tells you:** When determining which entities and consolidation levels SAMA's capital rules bite on, read the Basel Framework together with its Scope Guidance Note, because the Guidance Note is the framework's own statement of application boundaries — it fixes that local banks must comply at both standalone and consolidated level, and expressly carves out foreign bank branches. The 'references' link reflects that the Guidance Note forms the introductory scope section of the same document as the substantive framework. For a compliance decision you would rely on the Guidance Note to confirm perimeter (which subsidiaries, which tiers, insurance-entity exclusion, SAMA approval to exclude) before applying any capital or disclosure requirement.
- **Grounding — this node (Page 5):** "Local banks must comply with SAMA's Basel Framework (the Framework) at both standalone and consolidated level"
- **Grounding — related node (Page 3):** "The Basel Framework comprises the minimum risk-based capital including the relevant capital buffers, leverage, liquidity and large exposure standards"
