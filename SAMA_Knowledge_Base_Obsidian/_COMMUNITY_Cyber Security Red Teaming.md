# Cyber Security Red Teaming

**Cohesion:** 0.67 - moderately connected
**Members:** 3 nodes

## Why this community

Cyber security governance regime, specifically ethical red-teaming (adversarial testing) obligations layered on SAMA's Cyber Security Framework. Relevant to entities assessing mandatory penetration/red-team testing scope.

## How members connect

- The Red Teaming Regulatory Framework Circular cross-references both the Cyber Security Framework (the parent control regime) and the Financial Entities Ethical Red Teaming Framework (the detailed methodology).
- Hierarchy: Cyber Security Framework as the baseline; the red-teaming framework as the specialised testing regime; the circular as the instrument invoking/mandating them.
- Read the red-teaming framework as scoping which entities and what testing are required, subordinate to the broader cyber obligations.
