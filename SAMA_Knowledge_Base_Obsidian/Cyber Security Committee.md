# Cyber Security Committee

## Connections

### [[Board of Directors]] — `references` [EXTRACTED]
- **What this link tells you:** When allocating cyber security accountability in a SAMA-regulated bank, insurer or finance company, do not treat the cyber security committee as the entity holding ultimate responsibility — that remains with the board. Under the Cyber Security Framework the board holds ultimate responsibility but 'can delegate its cyber security responsibilities to a cyber security committee', which must in turn be 'established and be mandated by the board' and headed by an independent senior manager from a control function. For decisions on governance sign-off, conclude that any committee mandate, charter or risk-acceptance decision is only valid if traceable to a board mandate, and that residual accountability sits with the board regardless of delegation.
- **Grounding — this node (Page 13 / 3.1.1):** "A cyber security committee should be established and be mandated by the board."
- **Grounding — related node (Page 15 / 3.1.4):** "The Board of Directors has the ultimate responsibility for cyber security"

### [[Cyber Security Governance]] — `references` [EXTRACTED]
- **What this link tells you:** When reviewing escalation and risk-acceptance decisions, note that the Cyber Security Committee is a governance body whose sign-offs carry regulatory weight, not merely an internal forum. The Framework's risk-acceptance provisions require accepted risks to be reported to the cyber security committee and to not contradict SAMA regulations, situating the committee within the governance structure. In a compliance check you would verify that risk acceptances above defined limits actually reached the committee and remained within risk appetite, because unreported acceptances would be a governance-control failure.
- **Grounding — this node (Page 21):** "the accepted cyber security risk is within the risk appetite and is reported to the cyber security committee"
- **Grounding — related node (Page 21):** "the accepted cyber security risk does not contradict SAMA regulations"
