# System Change Management

## Connections

### [[Information Technology Governance Framework]] — `references` [EXTRACTED]
- **What this link tells you:** When scoping change-management obligations, note that section 3.4 of this Framework does not stand alone — it expressly cross-refers to the SAMA Cyber Security Framework, requiring that changes be 'reviewed and approved by the cyber security function before submitting to CAB'. So a Member Organization must satisfy both regimes concurrently for any production change. For a compliance decision, conclude that change governance, testing, approval and cyber-security sign-off are all mandated Control Requirements assessed under the maturity model, and that reliance on this Framework alone is insufficient where the cited Cyber Security Framework control also applies.
- **Grounding — this node (Page 28):** "Any changes in the information assets should be reviewed and approved by the cyber security function before submitting to 'CAB' (required as per the SAMA Cyber Security Framework...)."
- **Grounding — related node (Page 8):** "System Change Management."

### [[SAMA Cyber Security Framework]] — `references` [EXTRACTED]
- **What this link tells you:** When assessing change-management obligations, do not treat the IT Governance Framework as self-contained: it expressly incorporates a control from the separate SAMA Cyber Security Framework. Section 3.4.2 requires that any change to information assets 'be reviewed and approved by the cyber security function before submitting to CAB (required as per the SAMA Cyber Security Framework, 3.3.7... 4 — d).' Conclude that satisfying System Change Management here requires compliance with the cross-referenced Cyber Security Framework provision as well, so both instruments must be checked together for change approvals.
- **Grounding — this node (Page 27 / 3.4.2):** "reviewed and approved by the cyber security function before submitting to 'CAB' (required as per the SAMA Cyber Security Framework, 3.3.7 Change Management, Control Requirements, 4 — d)."
