# Supervisor Notification Form

## Connections

### [[Counter-Fraud Programme]] — `conceptually_related_to` [INFERRED]
- **What this link tells you:** When assessing the fraud-response element of the Counter-Fraud Programme, note that it carries an external SAMA reporting duty: Appendix C requires immediate notification to SAMA's ORC department of new fraud typologies and significant internal/external fraud incidents and accounting irregularities. The programme's 'response' domain therefore is not purely internal — it triggers a supervisory obligation with prompt supplementation of information gaps as investigations progress. A compliance reader should conclude that significant incidents must be escalated to SAMA using the notification form, not merely managed within the organisation.
