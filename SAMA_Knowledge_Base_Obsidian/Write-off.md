# Write-off

## Connections

### [[Default]] — `conceptually_related_to` [EXTRACTED]
- **What this link tells you:** When determining write-off timing, treat it as downstream of the default/Stage 3 determination rather than a separate policy: the write-off time limits (360/720/1,080 days) run 'once they are classified as stage 3 exposures,' and Stage 3 is itself tied to the default definition. Both provisions sit in the same SAMA Rules, and note the write-off provision clarifies that de-recognition 'does not eliminate the finance company's right to continue its recovery proceedings.' A reviewer should confirm that a defaulted/Stage 3 exposure is written off within the mandated windows (unless a more conservative policy applies) and not delayed 'in the hopes of an otherwise unknown reversal of fortune.'
- **Grounding — this node (Page 22):** "Unsecured exposures... should be written off within 360 days once they are classified as stage 3 exposures."
