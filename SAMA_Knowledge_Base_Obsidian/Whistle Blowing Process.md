# Whistle Blowing Process

## Connections

### [[Detect Domain]] — `references` [EXTRACTED]
- **What this link tells you:** When mapping detection obligations, note that the Whistle Blowing process (5.4) is a sub-domain of the Detect domain and functions as a human detection channel, distinct from automated monitoring. The Framework requires a whistle blowing process across multiple channels for employees and third parties, and cross-references an external instrument: it 'should comply with SAMA's Whistle Blowing Policy for Financial Institutions.' The consequence: a compliance reviewer must check conformity not only with this Framework but also with the separate Whistle Blowing Policy, and confirm the good-faith no-retaliation protection is in place.
- **Grounding — this node (Page 50 / Section 5.4):** "The process should comply with SAMA's Whistle Blowing Policy for Financial Institutions (Whistle Blowing Policy)."
- **Grounding — related node (Page 45 / Section 5):** "Fraud detection systems and controls are risk-based measures to identify fraud by looking for indicators in customer behaviours, transactional and non-transactional information."
