# SWIFT Customer Security Controls Framework

## Connections

### [[(Inter)national Industry Standards]] — `references` [EXTRACTED]
- **What this link tells you:** When scoping which external standards a Member Organization must meet, include the SWIFT Customer Security Controls Framework as a named mandatory standard under the SAMA Framework alongside PCI-DSS and EMV. Section 3.2.3 requires compliance with mandatory standards and specifically lists 'SWIFT Customer Security Controls Framework – March 2017'. For entities using SWIFT messaging, conclude that SWIFT CSCF attestation obligations are pulled into SAMA's enforceable compliance scope, so a failure there is also a Framework deficiency; verify the referenced version date remains current against SWIFT's later revisions.
