# Board of Directors

## Connections

### [[Cyber Security Committee]] — `references` [EXTRACTED]
- **What this link tells you:** When allocating cyber security accountability in a SAMA-regulated bank, insurer or finance company, do not treat the cyber security committee as the entity holding ultimate responsibility — that remains with the board. Under the Cyber Security Framework the board holds ultimate responsibility but 'can delegate its cyber security responsibilities to a cyber security committee', which must in turn be 'established and be mandated by the board' and headed by an independent senior manager from a control function. For decisions on governance sign-off, conclude that any committee mandate, charter or risk-acceptance decision is only valid if traceable to a board mandate, and that residual accountability sits with the board regardless of delegation.
- **Grounding — this node (Page 15 / 3.1.4):** "The Board of Directors has the ultimate responsibility for cyber security"
- **Grounding — related node (Page 13 / 3.1.1):** "A cyber security committee should be established and be mandated by the board."

### [[Cyber Security Governance]] — `references` [EXTRACTED]
- **What this link tells you:** When determining accountability for cyber security compliance, identify the board as the apex of the governance structure: the Framework places ultimate responsibility with the board and permits delegation to a cyber security committee, but the governance structure itself must be board-endorsed. This means a compliance or legal reviewer cannot treat committee delegation as a transfer of accountability — the board's endorsement and ultimate responsibility remain the anchor. Check that the governance structure, committee charter and mandate are demonstrably board-approved, since a governance regime lacking board endorsement is non-compliant regardless of how the committee operates.
- **Grounding — this node (Page 13 / 3.1):** "The ultimate responsibility for cyber security rests with the board ... can delegate its cyber security responsibilities to a cyber security committee"
- **Grounding — related node (Page 13 / 3.1.1):** "A cyber security governance structure should be defined and implemented, and should be endorsed by the board"
