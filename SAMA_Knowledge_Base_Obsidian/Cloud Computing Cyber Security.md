# Cloud Computing Cyber Security

## Connections

### [[SAMA (Saudi Arabian Monetary Authority)]] — `references` [EXTRACTED]
- **What this link tells you:** When considering cloud adoption, treat SAMA as the issuing authority whose Framework governs how cloud-related cyber-security risk may be treated, including the waiver and update procedures if a control cannot be met. The Framework's risk-response controls require any transfer or acceptance of cyber risk to remain consistent with SAMA regulations, and the appendices route framework exceptions to the Deputy Governor for IT Risk Supervision. You would conclude that cloud arrangements must be justified within SAMA's Framework and that deviations require formal SAMA waiver rather than unilateral risk acceptance.
- **Grounding — this node (Page 21 / Risk Response controls):** "the accepted cyber security risk ... does not contradict SAMA regulations"
- **Grounding — related node (Page 44 / Appendix E Waiver form):** "Request for Waiver from the SAMA Cyber Security Framework ... A submission to the deputy governor of SAMA IT Risk Supervision"

### [[Third Party Cyber Security]] — `references` [EXTRACTED]
- **What this link tells you:** When assessing a Member Organization's use of cloud services, treat cloud computing security as a specific instance of third-party cyber security rather than a standalone regime, because cloud providers are external parties handling the organization's information assets. Both sit within the SAMA Framework's control domains and the board retains ultimate responsibility for cyber security across all parties involved. A compliance reviewer should therefore expect cloud arrangements to satisfy the third-party control expectations (contractual cyber security obligations, risk assessment, oversight) and should not treat a cloud engagement as exempt from third-party due diligence.
- **Grounding — this node (Page 15 / 3.1.3(f)(6)):** "compliance with regulatory and contractual obligations are being met"
- **Grounding — related node (Page 15 / 3.1.4):** "all parties involved in cyber security should understand and take their role and responsibilities"
