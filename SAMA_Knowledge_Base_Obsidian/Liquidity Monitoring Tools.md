# Liquidity Monitoring Tools

## Connections

### [[Available Unencumbered Assets]] — `references` [EXTRACTED]
- **What this link tells you:** When scoping what a bank must report on assets it could mobilise for additional liquidity, treat 'available unencumbered assets' as the third prescribed Part 2 metric with defined reporting content, not a general risk-appetite disclosure. Paragraph 176 lists it (item III), and paragraphs 201–204 require reporting the amount, type and location of assets marketable as secondary-market collateral or eligible for central-bank standing facilities, plus re-pledgeable customer collateral. Conclude that only assets for which operational monetisation procedures are already in place count, and standing-facility eligibility excludes emergency assistance; check both conditions before reporting an asset as available.
- **Grounding — this node (Page 46 / para 176):** "The metrics discussed in this section include the following: ... III. Available unencumbered assets"
- **Grounding — related node (Page 50 / para 201):** "These metrics provide supervisors with data on the quantity and key characteristics, including currency denomination and location, of banks' available unencumbered assets."

### [[Concentration of Funding]] — `references` [EXTRACTED]
- **What this link tells you:** When determining a bank's LCR-related reporting obligations, recognise that 'Concentration of Funding' is not a standalone requirement but one of the Part 2 monitoring-tool metrics that sit alongside — and are distinct in status from — the binding LCR standard in Part 1. As a monitoring metric it defines specific thresholds (a significant counterparty/product exceeding 1% of the balance sheet; a significant currency being 5% or more of total liabilities) that supervisors use to detect negative trends, rather than a pass/fail ratio. You would conclude that funding-concentration figures are supervisory-monitoring inputs, and check the defined significance thresholds when scoping what must be reported under the monitoring-tools regime.
- **Grounding — this node (Page 46, para 174):** "In addition to the LCR outlined in Part 1 to be used as a standard, this section outlines metrics to be used as consistent monitoring tools."
- **Grounding — related node (Page 48-49, paras 188-195):** "identify those sources of wholesale funding ... withdrawal of this funding could trigger liquidity problems ... more than 1% of the bank's total balance sheet"

### [[Contractual Maturity Mismatch]] — `references` [EXTRACTED]
- **What this link tells you:** When identifying reporting obligations under Part 2, treat contractual maturity mismatch as the first of the five prescribed monitoring metrics, carrying specific data assumptions that a bank cannot restate at its discretion. Paragraph 176 lists it (item I), and paragraphs 179–183 fix the assumptions — no rollover of liabilities, no new asset contracts, separate reporting of open-maturity instruments, contingent liabilities and rehypothecated collateral. Conclude that the mismatch report must follow these prescribed contractual assumptions and at minimum cover the LCR categories; verify open-maturity and contingent-trigger items are reported separately.
- **Grounding — this node (Page 46 / para 176):** "The metrics discussed in this section include the following: I. Contractual maturity mismatch"
- **Grounding — related node (Page 46 / para 177):** "The contractual maturity mismatch profile identifies the gaps between the contractual inflows and outflows of liquidity for defined time bands."

### [[LCR by Significant Currency]] — `references` [EXTRACTED]
- **What this link tells you:** When determining what liquidity reporting a bank owes SAMA beyond the headline LCR, treat 'LCR by significant currency' as one of the five prescribed Part 2 monitoring metrics rather than an optional analysis. The parent document lists it explicitly (item IV) among the consistent monitoring tools that complement the single-currency LCR standard, so a bank must monitor and report foreign-currency LCR alongside the standard where SAMA applies these tools. Conclude that meeting the 100% LCR in one currency does not discharge the currency-mismatch monitoring obligation; check the foreign-currency LCR calculation (HQLA per currency / net outflows per currency, net of FX hedges) separately.
- **Grounding — this node (Page 46 / para 176):** "The metrics discussed in this section include the following: ... IV. LCR by significant currency"
- **Grounding — related node (Page 51 / para 209):** "in order to better capture potential currency mismatches, banks and supervisors should also monitor the LCR in significant currencies"

### [[Market-related Monitoring Tools]] — `references` [EXTRACTED]
- **What this link tells you:** When mapping the full set of liquidity-monitoring obligations, recognise that market-related monitoring tools are the fifth prescribed metric within the same Part 2 framework, not a distinct regime. Paragraph 176 lists them (item V) as a cornerstone metric supervisors use to assess a bank's liquidity risk, drawing on high-frequency market, financial-sector and bank-specific data as early-warning indicators. Conclude that this metric supplements the maturity-mismatch, funding-concentration, unencumbered-asset and currency metrics; do not treat market-data monitoring as external to the LCR supervisory package.
- **Grounding — this node (Page 46 / para 176):** "The metrics discussed in this section include the following: ... V. Market-related monitoring tools"
- **Grounding — related node (Page 52 / para 214):** "High frequency market data with little or no time lag can be used as early warning indicators in monitoring potential liquidity difficulties at banks."
