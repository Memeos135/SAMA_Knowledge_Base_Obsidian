- **What this link tells you:** When assessing what identifier must anchor entity records and KYB/beneficial-owner checks for non-governmental establishments, this link tells you the Unified Number (starting with 7) is the defined term the circular mandates as the replacement digital identity for commercial-registration and license numbers. The document is the source that defines and operationalizes the term, requiring institutions to add and link the Unified Number field while retaining the CR-number field until SAMA directs otherwise. You would conclude that entity onboarding, screening and beneficial-owner verification should be able to resolve both identifiers, and that the CR number must not be removed absent SAMA's instruction.
