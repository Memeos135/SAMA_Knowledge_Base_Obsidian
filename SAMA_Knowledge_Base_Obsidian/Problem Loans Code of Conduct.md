# Problem Loans Code of Conduct

## Connections

### [[Rules on Management of Problem Loans]] — `references` [EXTRACTED]
- **What this link tells you:** When assessing a bank's obligations toward stressed borrowers, treat the Code of Conduct (section 5.2) as a mandated component of the Problem Loans Rules, not an optional policy: the Rules require banks to 'develop a written Code of Conduct' defining a robust resolution process that gives viable borrowers a chance at a workout before enforcement. This operationalises the Rules' stated objective of fair treatment and rehabilitation of viable borrowers (especially MSMEs). Conclude that absence of a compliant, board-level Code of Conduct is itself a gap against the Rules, and that borrower-communication and workout procedures must align with relevant Laws and Regulations.
- **Grounding — this node (Page 11 / Section 5.2):** "Banks should develop a written Code of Conduct for managing problem loans ... to ensure that viable borrowers are provided a chance for reaching a workout solution, rather than invoking outright enforcement actions"
- **Grounding — related node (Page 4 / Section 1.2):** "To ensure banks look into aspects of customer conduct and fair treatment whilst dealing with problem loans, especially in instances involving the MSMEs"

### [[Workout Plan]] — `references` [EXTRACTED]
- **What this link tells you:** When evaluating conduct and fair-treatment compliance in a restructuring, read the workout plan as governed by the Code of Conduct, not separately from it, because the Rules require the Code to be 'reflected in all pertinent internal documentation with reference to problem loan resolution and be effectively implemented.' The Code sets the standards for borrower communication, information-gathering and financial assessment that feed the workout plan, so communication during the workout process must follow the Code's procedures. A reviewer should confirm the workout plan and related fee/communication practices trace back to a written Code of Conduct and are actually applied, since the Rules make the Code binding across problem-loan resolution.
- **Grounding — this node (Page 11 / 5.2):** "Banks should develop a written Code of Conduct for managing problem loans... to ensure that viable borrowers are provided a chance for reaching a workout solution."
- **Grounding — related node (Page 12-13 / Section 6):** "Communication with borrowers should be as per the procedures outlined in the bank's code of conduct."
