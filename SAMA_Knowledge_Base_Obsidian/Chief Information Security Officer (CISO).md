# Chief Information Security Officer (CISO)

## Connections

### [[Cyber Security Governance]] — `references` [EXTRACTED]
- **What this link tells you:** When mapping accountability under the SAMA Cyber Security Framework, treat the CISO role as an integral component of the governance regime rather than a standalone technical post. The Framework defines the cyber security function as headed by a CISO, independent of IT, reporting directly to the CEO/managing director, and places it within governance provisions where the Board holds ultimate responsibility. For a compliance assessment you would check that the reporting-line independence and Board oversight are demonstrably in place, since a CISO buried under IT would breach the governance control considerations.
- **Grounding — this node (Page 48):** "A function, independent from the information technology function, that is headed by a CISO and that reports directly to the CEO/managing director"
- **Grounding — related node (Page 15):** "The Board of Directors has the ultimate responsibility for cyber security"

### [[Cyber Security Risk Management Process]] — `references` [EXTRACTED]
- **What this link tells you:** When determining who owns cyber risk methodology, note the Framework makes the CISO responsible for developing and maintaining the cyber security risk management process, which must in turn be aligned with the organisation's enterprise risk management. This ties the CISO's role directly to the risk-management provisions in section 3.2. For a compliance assessment you would verify the risk process is CISO-owned, defined, approved, implemented, and demonstrably aligned to enterprise risk management, as a disconnected or unowned process would fail both the roles and the risk-management control considerations.
- **Grounding — this node (Page 16):** "The CISO should be responsible for: developing and maintaining: ... 4. cyber security risk management process"
- **Grounding — related node (Page 19):** "A cyber security risk management process should be defined, approved and implemented, and should be aligned with the Member Organization's enterprise risk management process"

### [[Cyber Security Strategy]] — `references` [EXTRACTED]
- **What this link tells you:** When assigning ownership of the cyber security strategy, attribute it to the CISO specifically: the Framework makes the CISO responsible for developing and maintaining the strategy. This is an explicit obligation-assignment within the governance/roles provisions, so the strategy is not a Board or IT deliverable in the first instance. For a compliance review you would confirm a named, independent CISO exists and that the current strategy document is under that officer's authorship and maintenance, since absence of that ownership indicates a control gap.
- **Grounding — this node (Page 16):** "The CISO should be responsible for: developing and maintaining: 1. cyber security strategy"
- **Grounding — related node (Page 16):** "developing and maintaining: 1. cyber security strategy"
