# Restructuring

## Connections

### [[Forbearance]] — `references` [EXTRACTED]
- **What this link tells you:** When assessing any modification of a credit contract, start from the Restructuring provision, because it defines forbearance as one of only two possible outcomes of restructuring — the other being renegotiation/refinancing/rescheduling — and the classification turns on whether the modified terms are concessionary and driven by the borrower's financial difficulty. Both nodes are in Section 7 of the same SAMA Rules, so a modification only qualifies as forbearance (with its Stage 2B/3A/3B reporting and cure consequences) when financial difficulty coexists; absent difficulty and value reduction it is mere renegotiation. A reviewer should therefore verify the financial-difficulty determination first, as it is the pivot that decides which restructuring branch — and which stage treatment — applies.
- **Grounding — this node (Page 17 / Section 7):** "Restructuring may only occur in the form of either forbearance or renegotiation and/or refinancing and/or rescheduling."
- **Grounding — related node (Page 17 / Section 7.1.1):** "The finance company grants a concession that it would not otherwise consider... A concession is granted only when the borrower is experiencing financial difficulty."
