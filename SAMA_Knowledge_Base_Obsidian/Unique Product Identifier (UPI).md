# Unique Product Identifier (UPI)

## Connections

### [[Section A Trade Reporting Requirements|Section A: Trade Reporting Requirements]] — `references` [EXTRACTED]
- **What this link tells you:** When completing Section A reporting templates, this link tells you the product identification field is governed by defined external standards, not free-form entry. The reporting fields require a product to be identified either by ISO 6166 ISIN (type I) or by the ISO 4914 UPI (type U, a 12-character alphanumeric code), depending on availability. Conclude that mandatory template completion under Section A includes correct UPI/ISIN classification, and that the choice between the two identifier types is determined by which standard code is available for the instrument.
- **Grounding — this node (Page 22 / Section 2b):** "U = UPI for product which an ISO 4914 UPI, 12-character alphanumeric code is available."
- **Grounding — related node (Page 7 / 3.1.3):** "A reporting bank is required to complete all the fields in the templates, which primarily relate to the economic terms of a transaction."
