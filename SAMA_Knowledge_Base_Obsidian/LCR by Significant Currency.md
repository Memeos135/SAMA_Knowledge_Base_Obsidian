# LCR by Significant Currency

## Connections

### [[Liquidity Coverage Ratio (LCR)]] — `conceptually_related_to` [EXTRACTED]
- **What this link tells you:** When determining what a bank must monitor beyond the headline ratio, note that the LCR itself 'is required to be met in one single currency,' but the document adds a separate expectation that banks and supervisors 'should also monitor the LCR in significant currencies' to capture currency-mismatch risk. The by-currency metric is a monitoring supplement, not an additional binding minimum, so a bank cannot substitute foreign-currency LCR compliance for the single-currency requirement. Conclude that both must be tracked, and check whether SAMA has designated significant currencies or set mismatch limits.
- **Grounding — this node (Page 51 / para 209-210):** "Foreign Currency LCR = Stock of HQLA in each significant currency / Total net cash outflows over a 30-day time period in each significant currency"
- **Grounding — related node (Page 51 / para 209):** "While the LCR is required to be met in one single currency ... banks and supervisors should also monitor the LCR in significant currencies"

### [[Liquidity Monitoring Tools]] — `references` [EXTRACTED]
- **What this link tells you:** When determining what liquidity reporting a bank owes SAMA beyond the headline LCR, treat 'LCR by significant currency' as one of the five prescribed Part 2 monitoring metrics rather than an optional analysis. The parent document lists it explicitly (item IV) among the consistent monitoring tools that complement the single-currency LCR standard, so a bank must monitor and report foreign-currency LCR alongside the standard where SAMA applies these tools. Conclude that meeting the 100% LCR in one currency does not discharge the currency-mismatch monitoring obligation; check the foreign-currency LCR calculation (HQLA per currency / net outflows per currency, net of FX hedges) separately.
- **Grounding — this node (Page 51 / para 209):** "in order to better capture potential currency mismatches, banks and supervisors should also monitor the LCR in significant currencies"
- **Grounding — related node (Page 46 / para 176):** "The metrics discussed in this section include the following: ... IV. LCR by significant currency"
