# Default Definition

## Connections

### [[Rules Governing Credit Risk Exposure Classification and Provisioning]] — `references` [EXTRACTED]
- **What this link tells you:** When determining whether a finance company must move an exposure to a higher-risk stage or recognise a loss, treat the 'default' definition as a binding regulatory trigger, not an accounting nicety. These Rules require finance companies to adopt SAMA's regulatory definition of default (both qualitative 'unlikeliness to pay' events and the 90-day quantitative criterion) and apply it consistently for regulatory and financial-reporting purposes, or document good reasons not to. You should therefore check that classification, provisioning, restaging and write-off decisions all key off this single default definition, and not rely on a firm-specific or purely IFRS 9 accounting default without documented justification.
- **Grounding — this node (Page 21):** "Finance companies are required to adopt SAMA's regulatory definition of default and apply it consistently for both, regulatory and financial reporting purposes, or document good reasons why not."
- **Grounding — related node (Page 4):** "These Rules set out the minimum requirements on Credit Risk Exposure Classification and Provisioning."

### [[Stage 123 Credit Risk Classification|Stage 1/2/3 Credit Risk Classification]] — `references` [EXTRACTED]
- **What this link tells you:** When classifying exposures across Stage 1/2/3, treat SAMA's default definition as the trigger that anchors Stage 3, because a Stage 3 exposure is defined as one 'assessed as impaired or otherwise is in default as determined in Section 8 of these Rules.' The default criteria (qualitative 'unlikeliness to pay' events plus the 90-day quantitative test) directly determine when an exposure sits in Stage 3, and the re-staging cure conditions reference the same default and past-due thresholds. Compliance consequence: you cannot assess staging accuracy without first applying SAMA's regulatory default definition consistently for both regulatory and financial reporting, and you should confirm that exit/cure periods (12 months non-retail, 6 months retail) are respected before any exposure is moved out of Stage 3.
- **Grounding — this node (Page 21 / Section 8):** "A default event occurs when either (or both) of the qualitative and quantitative criteria are met."
- **Grounding — related node (Page 7 (Stage 3 definition)):** "any exposure which is assessed as impaired or otherwise is in default as determined in Section 8 of these Rules."
