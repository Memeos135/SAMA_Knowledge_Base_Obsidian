# FATF (Financial Action Task Force)

## Connections

### [[Exchange Houses Operating Procedures Guide]] — `references` [EXTRACTED]
- **What this link tells you:** When determining how far the Exchange Houses Operating Procedures Guide binds a currency-exchange business, treat it as a SAMA implementing instrument that sits below the AML Law and its Bylaws but that expressly imports FATF standards as an interpretive floor. The Guide names FATF as the intergovernmental body setting the AML/CTF and proliferation-financing standards, and its appendices link directly to the FATF Recommendations and member-country lists, so the reference operationalises those standards into KSA exchange-house obligations rather than merely citing them. Practically, you should read the Guide's CDD/monitoring duties as intended to satisfy FATF expectations and check the current FATF high-risk/non-cooperative jurisdiction lists, since the Guide directs exchange houses to follow them — but rely on the Saudi AML Law/Bylaws and SAMA rules as the enforceable source, with FATF as the reference standard.
