# Default

## Connections

### [[Stage 123 Exposure Classification|Stage 1/2/3 Exposure Classification]] — `conceptually_related_to` [EXTRACTED]
- **What this link tells you:** When determining how a finance company must classify an exposure, treat the 'default' definition and the Stage 1/2/3 framework as two sides of the same obligation: a Stage 3 exposure is defined precisely as one that is impaired or 'in default as determined in Section 8 of these Rules,' and default's own qualitative criteria expressly reference 'allocates the credit exposure to Stage 3B status.' Because both concepts sit in the same SAMA Rules Governing Credit Risk Exposure Classification and Provisioning and are anchored to IFRS 9, a default event forces (or confirms) Stage 3 allocation and governs whether an exposure can cure back to lower stages. A compliance reviewer should therefore not assess default and staging in isolation — verify that the firm's default indicators feed consistently into stage allocation and the documented cure-period re-staging conditions.
- **Grounding — this node (Page 21):** "A default event occurs when either (or both) of the qualitative and quantitative criteria are met... The finance company allocates the credit exposure to Stage 3B status"
- **Grounding — related node (Page 7):** "any exposure which is assessed as impaired or otherwise is in default as determined in Section 8 of these Rules"

### [[Write-off]] — `conceptually_related_to` [EXTRACTED]
- **What this link tells you:** When determining write-off timing, treat it as downstream of the default/Stage 3 determination rather than a separate policy: the write-off time limits (360/720/1,080 days) run 'once they are classified as stage 3 exposures,' and Stage 3 is itself tied to the default definition. Both provisions sit in the same SAMA Rules, and note the write-off provision clarifies that de-recognition 'does not eliminate the finance company's right to continue its recovery proceedings.' A reviewer should confirm that a defaulted/Stage 3 exposure is written off within the mandated windows (unless a more conservative policy applies) and not delayed 'in the hopes of an otherwise unknown reversal of fortune.'
- **Grounding — this node (Page 21):** "A default event occurs when either (or both) of the qualitative and quantitative criteria are met"
- **Grounding — related node (Page 22):** "Unsecured exposures... should be written off within 360 days once they are classified as stage 3 exposures."
