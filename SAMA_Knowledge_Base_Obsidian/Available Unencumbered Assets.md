# Available Unencumbered Assets

## Connections

### [[Liquidity Monitoring Tools]] — `references` [EXTRACTED]
- **What this link tells you:** When scoping what a bank must report on assets it could mobilise for additional liquidity, treat 'available unencumbered assets' as the third prescribed Part 2 metric with defined reporting content, not a general risk-appetite disclosure. Paragraph 176 lists it (item III), and paragraphs 201–204 require reporting the amount, type and location of assets marketable as secondary-market collateral or eligible for central-bank standing facilities, plus re-pledgeable customer collateral. Conclude that only assets for which operational monetisation procedures are already in place count, and standing-facility eligibility excludes emergency assistance; check both conditions before reporting an asset as available.
- **Grounding — this node (Page 50 / para 201):** "These metrics provide supervisors with data on the quantity and key characteristics, including currency denomination and location, of banks' available unencumbered assets."
- **Grounding — related node (Page 46 / para 176):** "The metrics discussed in this section include the following: ... III. Available unencumbered assets"
