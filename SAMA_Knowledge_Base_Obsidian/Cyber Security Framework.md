# Cyber Security Framework

## Connections

### [[Authentication Standard]] — `references` [EXTRACTED]
- **What this link tells you:** When scoping authentication obligations under the Counter-Fraud Framework, do not treat them as self-contained: the Framework expressly directs Member Organisations, when defining their authentication standard, to apply specific Cyber Security Framework control requirements (3.3.5 Identity and access management; 3.3.13 Electronic Banking Services). Because the Counter-Fraud Framework states it 'should be implemented in conjunction with' SAMA's Cyber Security Framework for cyber-specific requirements, compliance with the authentication principle is only demonstrable by cross-checking against those named CSF controls. Conclude that an authentication standard must satisfy both instruments jointly, with input from both the Counter-Fraud Department and Cyber Security Team, and cannot be assessed against the fraud text alone.
- **Grounding — this node (Page 7 / 1.3 Scope):** "The Framework should be implemented in conjunction with other SAMA frameworks, in particular SAMA's Cyber Security Framework ... which should be referred to for specific Cyber Security related requirements."
- **Grounding — related node (Page 37 / 4.4 Authentication):** "Member Organisations should take note of the following Control Requirements outlined in The Cyber Security Framework: 3.3.5 Identity and access management; 3.3.13 Electronic Banking Services"

### [[Counter-Fraud Framework]] — `references` [EXTRACTED]
- **What this link tells you:** When scoping a Member Organisation's counter-fraud obligations, do not treat the Counter-Fraud Framework as self-contained — it expressly directs that it 'should be implemented in conjunction with' SAMA's Cyber Security Framework for cyber-specific requirements, and mandates operational alignment of Counter-Fraud, Cyber Security and Financial Crime teams. This means compliance is assessed against both frameworks jointly where fraud and cyber controls overlap. Conclude that you must cross-reference the Cyber Security Framework for the cyber-related control detail and align the two regimes rather than satisfying counter-fraud requirements alone.
- **Grounding — this node (Page 7 / 1.3 Scope):** "The Framework should be implemented in conjunction with other SAMA frameworks, in particular SAMA's Cyber Security Framework... referred to for specific Cyber Security related requirements."
- **Grounding — related node (Page 20 / Control Requirements):** "Ensuring alignment of Counter-Fraud capabilities with Cyber Security and Financial Crime."
