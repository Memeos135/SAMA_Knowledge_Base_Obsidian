# Supervisory Factor (SF)

## Connections

### [[Add-on for Interest Rate Derivatives]] — `references` [EXTRACTED]
- **What this link tells you:** When verifying the interest-rate add-on, the supervisory factor is the prescribed multiplier applied per trade to convert effective notionals into potential future exposure, so the two must be assessed together. The supervisory factor is the SAMA-calibrated change in value of the underlying risk factor, reflecting volatility, and it is applied when building the asset-class add-on. You should conclude that using the wrong supervisory factor (which is fixed by SAMA, not bank discretion) directly misstates the IR add-on, so confirm the correct calibrated SF for the asset class has been applied before relying on the add-on figure.
- **Grounding — this node (Page 576):** "A supervisory factor (SF) is identified for each individual trade... the supervisory specified change in value of the underlying risk factor... calibrated to take into account the volatility of underlying risk factors"
- **Grounding — related node (Page 586 / 6.58-6.59):** "the aggregate add-on for a netting set... is calculated as the sum of the add-ons calculated for each asset class within the netting set"
