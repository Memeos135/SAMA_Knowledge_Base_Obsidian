# Shari'ah Governance Framework

## Connections

### [[Risk Management Framework for Shari'ah Compliant Banking]] — `references` [EXTRACTED]
- **What this link tells you:** When assessing a bank's Shari'ah-compliance obligations, do not read the RMF in isolation: its Introduction states the framework 'shall be read together with the Shari'ah Governance Framework for Shari'ah Compliant Banking issued by SAMA (February 2020) and any subsequent updates.' The two instruments are complementary — the RMF addresses identification and management of risk (including SNCR under operational risk), while the Governance Framework supplies the governance structures (e.g. Shari'ah Committee) that the RMF assumes are in place. For a compliance decision you must map obligations across both documents and use the current version of the Governance Framework, since RMF requirements presuppose its governance mechanisms.
- **Grounding — this node (Page 13 / 9.6):** "Banks shall ensure that they comply at all times with the Shari'ah rules and principles as approved/instructed by the banks' Shari'ah Committee"
- **Grounding — related node (Page 4 / Introduction):** "This framework shall be read together with the Shari'ah Governance Framework for Shari'ah Compliant Banking issued by SAMA (February 2020) and any subsequent updates."
