# Red Team Evaluation Report (RTER)

## Connections

### [[Red Teaming Provider]] — `references` [EXTRACTED]
- **What this link tells you:** When verifying deliverables owed by a contracted Red Teaming Provider, note that the reporting output (the basis of the Red Team Evaluation Report) is a defined obligation of the Provider, not merely a courtesy. After completing or stopping the test, the Provider must prepare initial observations and findings which provide the basis for evaluating the Blue Team's detection and response — and these feed the formal evaluation report. A reviewer should confirm the engagement contract and Appendix A provider requirements tie the Provider's methodology to producing this reporting deliverable, since the RTER underpins all downstream remediation.
- **Grounding — this node (Page 15 / 5.4 Reporting):** "the Red Teaming Provider should prepare their initial observations and findings ... These observations and findings provide the basis of evaluating the detection and response capabilities of the Blue Team."
- **Grounding — related node (Page 20 / Appendix A):** "The Red Teaming Provider should have a clearly defined process ... the preparation, scenario development, execution and lessons"

### [[Remediation Plan (RP)]] — `references` [EXTRACTED]
- **What this link tells you:** When checking closure of a red teaming exercise, treat the Remediation Plan as directly derived from the Red Team Evaluation Report — it cannot be assessed in isolation. The framework requires the White Team to draft the Remediation Plan based on the Red Teaming Evaluation Report (and the Blue Team Report), setting improvement areas, priorities and a roadmap. A reviewer should confirm that RP recommendations trace back to RTER findings and that progress is periodically reported to the Cyber Security Committee and the Green Team, since that reporting obligation is what makes the exercise's outcome supervisable.
- **Grounding — this node (Page 15 / 5.4 Reporting):** "These observations and findings provide the basis of evaluating the detection and response capabilities of the Blue Team."
- **Grounding — related node (Page 24 / Remediation Plan (RP)):** "The White Team should draft a Remediation Plan, which should be based on the Red Teaming Evaluation Report and the Blue Team Report."
