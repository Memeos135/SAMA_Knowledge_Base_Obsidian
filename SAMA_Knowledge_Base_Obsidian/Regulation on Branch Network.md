# Regulation on Branch Network

## Connections

### [[Branch Network Policy]] — `references` [EXTRACTED]
- **What this link tells you:** When advising a bank on branch openings, treat the Branch Network Policy as the mandatory precondition for any licensing request, not merely internal documentation. The Regulation requires every locally incorporated bank (and foreign-bank branches expanding beyond three branches) to prepare, board-approve, and submit this Policy, and it makes new-branch proposals conditional on being 'as per their approved Branch Network Policy.' Practically, verify that a SAMA-approved Policy exists before assessing any opening/closure/relocation action, and note that once approved it displaces the Annual Branch Expansion Plan submission.
- **Grounding — this node (Page 6 / Sec 5.1):** "Banks are required to prepare a Branch Network Policy for opening, closing and relocating of branches, service centers, and remittance centers."
- **Grounding — related node (Page 9 / Sec 6.2):** "Banks will submit the proposal for obtaining license of a new branch... as per their approved Branch Network Policy."

### [[Branch Network Zones]] — `references` [EXTRACTED]
- **What this link tells you:** When determining whether SAMA's prior approval is needed for a branch action, the zone classification is the operative variable that can waive that requirement. The Regulation ties the prior-approval exemption to zones: opening within the same zone using an inactive license, or opening in a smaller zone using a larger zone's inactive license, avoids prior approval (subject to a two-months-advance amendment request). Conclude that any assessment of approval obligations must first fix the branch's zone of location and the inactive-license source zone, since these determine whether the bank may proceed without SAMA sign-off.
- **Grounding — this node (Page 9 / Sec 6.4):** "SAMA's prior approval... will not be required if such branch/center is being opened within the same zone by using the inactive licenses"
- **Grounding — related node (Page 9 / Sec 6.2):** "including name of the city, tentative location, zone of location, brief justification for choice of the city/location"

### [[Financial Inclusion]] — `references` [EXTRACTED]
- **What this link tells you:** When evaluating whether a bank's branch decisions comply, understand that promoting financial inclusion is a stated regulatory objective that SAMA actively reviews, not aspirational language. The Regulation lists 'promoting financial inclusion' among its objectives and requires the Branch Network Policy to set out the bank's approach to it, and SAMA weighs outreach measures when granting its no-objection. Conclude that a Policy silent on inclusion/priority-area outreach risks SAMA rejection, so this element should be checked substantively rather than treated as boilerplate.
- **Grounding — this node (Page 6 / Sec 3(a)):** "Promoting financial inclusion and increasing outreach of financial services to the priority areas"
- **Grounding — related node (Page 7 / Sec 5.1(c)):** "Bank's approach towards promoting financial inclusion and increasing outreach of financial services"
