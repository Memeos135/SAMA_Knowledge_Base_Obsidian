# Branch Network Policy

## Connections

### [[Financial Inclusion]] — `conceptually_related_to` [EXTRACTED]
- **What this link tells you:** When drafting or reviewing a Branch Network Policy, treat financial inclusion as a required content element of the Policy itself, not a separate obligation. The same Regulation both mandates the Policy and prescribes that it cover the bank's approach to promoting financial inclusion and serving priority areas as part of CSR, which SAMA then reviews before granting no-objection. The practical consequence: assessing Policy completeness and assessing inclusion commitments are the same exercise, so a compliance check of one should confirm the other.
- **Grounding — this node (Page 7 / Sec 5.1(h)):** "Plans for serving customers in priority areas as a part of corporate social responsibility (CSR)."
- **Grounding — related node (Page 7 / Sec 5.1(c)):** "Bank's approach towards promoting financial inclusion and increasing outreach of financial services"

### [[Regulation on Branch Network]] — `references` [EXTRACTED]
- **What this link tells you:** When advising a bank on branch openings, treat the Branch Network Policy as the mandatory precondition for any licensing request, not merely internal documentation. The Regulation requires every locally incorporated bank (and foreign-bank branches expanding beyond three branches) to prepare, board-approve, and submit this Policy, and it makes new-branch proposals conditional on being 'as per their approved Branch Network Policy.' Practically, verify that a SAMA-approved Policy exists before assessing any opening/closure/relocation action, and note that once approved it displaces the Annual Branch Expansion Plan submission.
- **Grounding — this node (Page 9 / Sec 6.2):** "Banks will submit the proposal for obtaining license of a new branch... as per their approved Branch Network Policy."
- **Grounding — related node (Page 6 / Sec 5.1):** "Banks are required to prepare a Branch Network Policy for opening, closing and relocating of branches, service centers, and remittance centers."
