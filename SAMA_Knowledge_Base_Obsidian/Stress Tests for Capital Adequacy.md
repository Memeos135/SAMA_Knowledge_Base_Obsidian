# Stress Tests for Capital Adequacy

## Connections

### [[Risk Rating System Operations]] — `references` [EXTRACTED]
- **What this link tells you:** When assessing an IRB bank's rating operations for capital-adequacy purposes, note that a sound stress-testing process is a required operational component, not a discretionary enhancement. Para 16.50 mandates that an IRB bank 'must have in place sound stress testing processes' identifying adverse events (economic/industry downturns, market-risk events, liquidity conditions) and assessing resilience of credit exposures. A reviewer should therefore treat the rating system's data and estimates (PDs/LGDs/EADs) as inputs that must feed a documented stress-testing capability, and conclude that absence of such stress testing is itself a minimum-standards deficiency.
- **Grounding — this node (Page 192 / 16.50):** "An IRB bank must have in place sound stress testing processes for use in the assessment of capital adequacy."
- **Grounding — related node (Page 192 / 16.49):** "Banks must retain data used in the process of allocating exposures to pools... as well as data on delinquency."
