# Cyber Security Strategy

## Connections

### [[Chief Information Security Officer (CISO)]] — `references` [EXTRACTED]
- **What this link tells you:** When assigning ownership of the cyber security strategy, attribute it to the CISO specifically: the Framework makes the CISO responsible for developing and maintaining the strategy. This is an explicit obligation-assignment within the governance/roles provisions, so the strategy is not a Board or IT deliverable in the first instance. For a compliance review you would confirm a named, independent CISO exists and that the current strategy document is under that officer's authorship and maintenance, since absence of that ownership indicates a control gap.
- **Grounding — this node (Page 16):** "developing and maintaining: 1. cyber security strategy"
- **Grounding — related node (Page 16):** "The CISO should be responsible for: developing and maintaining: 1. cyber security strategy"

### [[Cyber Security Leadership and Governance]] — `references` [EXTRACTED]
- **What this link tells you:** When assessing governance obligations, read the Cyber Security Strategy as a governance-domain deliverable owned at defined levels, not a free-floating planning exercise. The framework requires the cyber security policy to state the board's intent and overall objectives, while the CISO is expressly made responsible for 'developing and maintaining' the cyber security strategy — linking strategy directly to the leadership/governance structure. A reviewer should verify that the strategy exists, aligns with board-approved objectives, and has a documented CISO owner, and should treat absence of these as a governance-domain finding.
- **Grounding — this node (Page 16 / 3.1.2):** "The CISO should be responsible for: a. developing and maintaining: 1. cyber security strategy"
- **Grounding — related node (Page 15 / 3.1.3):** "a statement of the board's intent, supporting the cyber security objectives"

### [[Cyber Security Policy]] — `references` [EXTRACTED]
- **What this link tells you:** When evaluating the documentation hierarchy, treat the cyber security policy and strategy as distinct but linked instruments both owned by the CISO, with the policy carrying Board intent and the strategy setting direction. The Framework lists both as CISO develop-and-maintain deliverables and requires the policy to include a statement of the board's intent and reference supporting standards. For a compliance check you would confirm the policy and strategy are consistent and that the policy contains the mandated elements; misalignment between them signals an incomplete governance framework.
- **Grounding — this node (Page 16):** "developing and maintaining: 1. cyber security strategy; 2. cyber security policy"
- **Grounding — related node (Page 15):** "The cyber security policy should include: ... a statement of the board's intent, supporting the cyber security objectives"
