# Material Functions

## Connections

### [[Rules on Outsourcing for Finance Companies]] — `references` [EXTRACTED]
- **What this link tells you:** When determining whether SAMA's prior non-objection is required before an outsourcing, the classification of the function as 'Material' is the trigger — so apply the defined test first. Material Functions are defined as any function whose default or disruption may affect the company's activities, reputation or financial situation, or that involves sharing/transferring/processing/storing consumers' data; the Rules then require the company to classify each function and to seek SAMA's written non-objection at least 30 working days before outsourcing or renewing material functions. Conclude that the definition (plus the non-exhaustive Appendix 1 examples such as internal audit, debt collection, data storage) governs the approval obligation, so a misclassification as non-material to avoid the 30-day non-objection step is itself a compliance risk.
