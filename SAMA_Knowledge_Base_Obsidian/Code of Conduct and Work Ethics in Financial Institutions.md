# Code of Conduct and Work Ethics in Financial Institutions

## Connections

### [[Compliance Principles for Finance Companies]] — `references` [EXTRACTED]
- **What this link tells you:** When scoping compliance obligations for a finance company, do not treat the Code of Conduct and the Compliance Principles as interchangeable — the Compliance Principles expressly list the Code of Conduct among the other related instruments that continue to bind alongside them. The Compliance Principles state they do not derogate from other applicable requirements, "منها على سبيل المثال لا الحصر ... مبادئ السلوك وأخلاقيات العمل في المؤسسات المالية." Conclude that a finance company must satisfy both: the Code sets the conduct/ethics floor for staff, while the Compliance Principles allocate compliance-function responsibilities, and compliance with one does not discharge the other.

### [[Internal Audit Principles for Finance Companies]] — `references` [EXTRACTED]
- **What this link tells you:** When allocating internal governance duties in a finance company, read the Internal Audit Principles and the Code of Conduct as complementary parts of the same governance regime rather than as one covering the other. The Internal Audit Principles define internal audit as an independent assurance function evaluating the internal control system, while the Code of Conduct sets the ethics/behaviour floor applying to all staff (including internal auditors, who must be free of conflicts). Conclude that internal audit's scope includes testing adherence to the conduct standards, and that meeting the Code does not substitute for the separate internal-audit obligations imposed on the board, audit committee, executive management, and the audit function.
