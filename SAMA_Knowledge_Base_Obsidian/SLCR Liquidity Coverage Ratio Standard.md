# SLCR Liquidity Coverage Ratio Standard

## Connections

### [[Template LIQ1 Liquidity Coverage Ratio|Template LIQ1: Liquidity Coverage Ratio]] — `references` [EXTRACTED]
- **What this link tells you:** When completing the LIQ1 LCR disclosure, treat the SLCR standard as the source of the definitions and rates that populate it: LIQ1's HQLA, inflow/outflow and net-cash-outflow figures must be built using SLCR's defined categories (e.g. unsecured debt per SLCR110, secured wholesale funding per SLCR112–114) and its haircut, inflow/outflow-rate and cap rules. LIQ1 is a presentation template whose numbers are only correct if derived under SLCR. For compliance review, resolve any classification or weighting question against the SLCR provisions cited, not the template captions.

### [[Template LIQ2 Net Stable Funding Ratio|Template LIQ2: Net Stable Funding Ratio]] — `references` [EXTRACTED]
- **What this link tells you:** When completing Pillar 3 liquidity disclosures, do not treat Template LIQ2 (NSFR) and the SLCR (Liquidity Coverage Ratio) standard as isolated: the disclosure templates in this framework are populated using cross-references to SLCR-defined line items (e.g. SLCR110, SLCR112–114 for retail/wholesale funding categories). This means the classification and haircut/cap rules that govern the numbers you disclose are set by the SLCR standard, not the template itself. Conclude that to validate a disclosed figure you must trace the definition back to the corresponding SLCR paragraph rather than relying on the template caption alone.
