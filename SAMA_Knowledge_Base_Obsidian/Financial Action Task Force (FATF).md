# Financial Action Task Force (FATF)

## Connections

### [[Guide to Rules Governing Banks' Remittance Centers]] — `references` [EXTRACTED]
- **What this link tells you:** When assessing risk classification for remittance customers, use FATF as the operative external benchmark this Guide incorporates: the Guide defines FATF and then requires enhanced due diligence for transactions involving jurisdictions the FATF website identifies as not adequately implementing AML/CFT recommendations. This makes FATF listings a live input into the center's risk-based approach rather than merely informational. A reader should conclude that high-risk-jurisdiction and PEP triggers derive from FATF standards and must feed the center's enhanced-measures and rejection decisions (e.g., funds from FATF-warned countries).
- **Grounding — this node (Page 13 / Section 9.6):** "those mentioned on the FATF website as being jurisdictions that do not adequately implement the recommendations related to AML/CFT"
- **Grounding — related node (Page 6 / Section 3 Definitions):** "Financial Action Task Force (FATF): An inter-governmental body that sets standards and promotes effective implementation of legal, regulatory and operational measures to combat money laundering"
