# Qualifying Revolving Retail Exposures

## Connections

### [[IRB Approach Overview]] — `references` [EXTRACTED]
- **What this link tells you:** When segmenting retail exposures under IRB, treat QRRE as a mandatory separately-identified sub-class, not a discretionary category. The IRB overview requires banks to identify three retail sub-classes, and the QRRE definition sets cumulative criteria (revolving, unsecured, uncommitted exposures with fluctuating balances) that must all be satisfied at sub-portfolio level. You would conclude that QRRE classification drives a distinct risk-weight treatment, so verify each defining criterion at the sub-portfolio level before assigning an exposure to the QRRE pool. Note the retail/QRRE definitions here differ from the standardized-approach 'regulatory retail' and 'transactor' concepts on pages 32–33.
- **Grounding — this node (Page 98 / 10.22):** "All of the following criteria must be satisfied for a sub-portfolio to be treated as a qualifying revolving retail exposure (QRRE)."
- **Grounding — related node (Page 98 / 10.21):** "banks are required to identify separately three sub-classes of exposures... (2) Qualifying revolving retail exposures, as defined in the following paragraph."

### [[IRB Risk Weight Functions]] — `references` [EXTRACTED]
- **What this link tells you:** When classifying a revolving retail sub-portfolio, note that meeting the QRRE definition determines which risk-weight function applies — QRRE is one of three IRB retail sub-classes and carries its own function distinct from 'other retail'. The purchased-receivables rules confirm the consequence: 'if banks cannot comply with the standards for qualifying revolving retail exposures (defined in paragraph 10.22), they should use the risk-weight function for other retail exposures.' For a compliance decision, verify that every QRRE criterion (revolving, unsecured, uncommitted, sub-portfolio segmentation) is satisfied, because failing the definition forces a different, potentially higher-capital risk-weight function.
- **Grounding — this node (Page 98 / Para 10.22):** "All of the following criteria must be satisfied for a sub-portfolio to be treated as a qualifying revolving retail exposure (QRRE)."
- **Grounding — related node (Page 168 / Para 14.2):** "if banks cannot comply with the standards for qualifying revolving retail exposures (defined in paragraph 10.22), they should use the risk-weight function for other retail exposures"
