# IT Project Management

## Connections

### [[SAMA Cyber Security Framework]] — `references` [EXTRACTED]
- **What this link tells you:** When scoping which IT controls a Member Organization must implement, treat IT Project Management (3.4.10) as a mandated subdomain sitting within the same SAMA IT Governance Framework rather than as optional project discipline. The Framework states each subdomain carries a binding Principle and Control Requirements that Member Organizations 'are responsible for implementing and complying with,' and IT Project Management sets a formally defined, approved lifecycle process with a steering committee and risk assessment. For a compliance assessment you should conclude that project-lifecycle governance is a scored, enforceable control area, not a best-practice recommendation.
- **Grounding — this node (Page 32 / 3.4.10):** "Formal process should be defined, approved and implemented to effectively manage IT project and related risks throughout the lifecycle of the project."
- **Grounding — related node (Page 8 / subdomain structure):** "Per subdomain, the Framework states a principle and Control Requirements... The Control Requirements reflects the mandated IT controls that should be considered."
