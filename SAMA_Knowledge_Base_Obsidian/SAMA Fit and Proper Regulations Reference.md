# SAMA Fit and Proper Regulations Reference

## Connections

### [[Corporate Governance and Risk Management]] — `references` [EXTRACTED]
- **What this link tells you:** When assessing a DTFC's senior-management appointments, treat the corporate-governance obligation and the Fit and Proper regime as a single gating process. Chapter 3 requires a Job Description for each senior manager that must be included in every application to SAMA for pre-approval 'as per SAMA's fit and proper regulations,' and re-submitted on any significant change of responsibilities. You should conclude that senior manager pre-approval is conditioned on the separate SAMA Fit and Proper Regulations — so a governance structure cannot be evidenced as complete without confirming each pre-approval and JD/MRDD was processed under that fit-and-proper standard.
- **Grounding — this node (Page 6 / Chapter 3, para 10):** "be updated and resubmitted if there is a significant change to the senior manager's responsibilities as per SAMA's fit and proper regulations"
- **Grounding — related node (Page 6 / Chapter 3, para 10(ii)-(iii)):** "Be included in every application to SAMA for pre-approval as a senior manager as per SAMA's fit and proper regulations"
