# Branch Network Zones

## Connections

### [[Regulation on Branch Network]] — `references` [EXTRACTED]
- **What this link tells you:** When determining whether SAMA's prior approval is needed for a branch action, the zone classification is the operative variable that can waive that requirement. The Regulation ties the prior-approval exemption to zones: opening within the same zone using an inactive license, or opening in a smaller zone using a larger zone's inactive license, avoids prior approval (subject to a two-months-advance amendment request). Conclude that any assessment of approval obligations must first fix the branch's zone of location and the inactive-license source zone, since these determine whether the bank may proceed without SAMA sign-off.
- **Grounding — this node (Page 9 / Sec 6.2):** "including name of the city, tentative location, zone of location, brief justification for choice of the city/location"
- **Grounding — related node (Page 9 / Sec 6.4):** "SAMA's prior approval... will not be required if such branch/center is being opened within the same zone by using the inactive licenses"
