# Red Teaming Regulatory Framework Circular

## Connections

### [[Cyber Security Framework]] — `references` [EXTRACTED]
- **What this link tells you:** When determining a financial institution's ongoing cyber obligations, read the red-teaming circular as reinforcing that self-testing must be performed 'in accordance with the requirements of the Cyber Security Framework' — the circular does not stand alone but points back to the CSF as the governing baseline. The Arabic text directs financial entities to independently and periodically test system readiness and develop it per the CSF requirements. A compliance reviewer should therefore treat the CSF as the primary source of the substantive control obligations and this circular as adding a testing/assurance expectation on top of it.

### [[Financial Entities Ethical Red Teaming Framework]] — `references` [EXTRACTED]
- **What this link tells you:** When scoping a financial institution's testing obligations, note that this circular formally adopts the Financial Entities Ethical Red Teaming Framework and announces SAMA will run periodic tests applying it to financial institutions to assess readiness. The circular is the enabling instrument; the named Framework is the substantive standard governing scenario-based attack simulation. A compliance reviewer should conclude the Framework is binding on the distribution list (banks, licensed payment companies, insurers) and that institutions should obtain the actual Framework text (distributed to compliance departments by email) rather than relying on the circular alone.
