# Template KM2 - TLAC Key Metrics

## Connections

### [[Pillar 3 Disclosure Requirements Framework]] — `references` [EXTRACTED]
- **What this link tells you:** When scoping disclosure duties, note that KM2 is a conditional, not universal, component of the Pillar 3 framework: section 12.1.2 lists it, but section 12.2 states the TLAC disclosures need not be completed unless SAMA specifies otherwise, and KM2's own scope limits it to resolution groups of G-SIBs. So the framework both mandates and gates KM2 by institution type and SAMA activation. Conclude that a non-G-SIB or a bank not designated by SAMA should not treat KM2 as an active obligation, and that any KM2 filing becomes due only from the TLAC conformance date.
- **Grounding — this node (Page 748):** "Scope of application: The template is mandatory for all resolution groups of G-SIBs."
- **Grounding — related node (Page 745):** "The disclosure requirements related to TLAC are not required to be completed by banks unless otherwise specified by SAMA."

### [[Template TLAC1 - TLAC Composition]] — `references` [EXTRACTED]
- **What this link tells you:** When preparing G-SIB resolution-group disclosures, read Template KM2 (key TLAC metrics) and Template TLAC1 (composition of TLAC) as two views of the same underlying figures, so the summary ratios in KM2 must reconcile to the detailed composition reported in TLAC1. Both templates are mandatory only for G-SIB resolution groups and are built on the same defined base — TLAC available, RWA and leverage exposure measured at resolution-group level per the FSB TLAC Term Sheet. Conclude that inconsistency between the KM2 headline metrics and the TLAC1 breakdown signals an error, and that both are governed by the same scope trigger (G-SIB / TLAC conformance date) rather than applying to all banks.
- **Grounding — this node (Page 748 / Template KM2):** "Provide summary information about total loss-absorbing capacity (TLAC) available, and TLAC requirements applied, at resolution group level"
- **Grounding — related node (Page 773 / Template TLAC1):** "Provide details of the composition of a G-SIB's TLAC. ... mandatory for all G-SIBs. It should be completed at the level of each resolution group"

### [[Total Loss-Absorbing Capacity]] — `references` [EXTRACTED]
- **What this link tells you:** When applying Template KM2, treat 'Total Loss-Absorbing Capacity' as the defined quantity the template measures rather than a loose label — the template's rows are ratios and amounts of TLAC available against RWA and leverage exposure at resolution-group level. The link is supported because KM2 exists solely to disclose TLAC metrics for G-SIB resolution groups. Conclude that the meaning of every KM2 figure depends on the TLAC definition and its Term Sheet adjustments, and that KM2 obligations do not apply where TLAC requirements are not imposed by SAMA.
- **Grounding — this node (Page 748 / Template KM2):** "Total Loss Absorbing Capacity (TLAC) available... TLAC as a percentage of RWA (row1/row2)"
- **Grounding — related node (Page 774):** "TLAC (as a percentage of RWA adjusted as permitted under the TLAC regime)"
