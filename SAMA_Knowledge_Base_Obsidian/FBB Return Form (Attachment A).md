# FBB Return Form (Attachment A)

## Connections

### [[Regulations for Foreign Banks Branches (FBB)]] — `references` [EXTRACTED]
- **What this link tells you:** When determining what an FBB must actually file with SAMA, treat Attachment A (FBB Return A) as the operative instrument that the regulation's reporting duty points to: the body text mandates quarterly submission of information 'in accordance with' this Return, within 30 days of quarter-end, and additionally requires all outsourcing activities to be reported through the same form. The link tells you the substantive scope of the reporting obligation is defined by the attachment, not the narrative alone. Conclude that compliance turns on completing and timely-submitting the Return itself, and that outsourcing reporting is folded into this same channel rather than a separate one.
- **Grounding — this node (Page 15 / para 48):** "All outsourcing activities must also be reported using the FBB Return Form (Attachment A)."
- **Grounding — related node (Page 16 / para 55):** "All FBBs must provide SAMA with information in accordance with the FBB Return A (Attachment A) accompanying these regulations... within 30 days of the date to which the information relates."
