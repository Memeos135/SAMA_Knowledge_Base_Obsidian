# Cyber Security Leadership and Governance

## Connections

### [[Cyber Security Governance]] — `references` [EXTRACTED]
- **What this link tells you:** When mapping the Framework's structure, read 'Cyber Security Governance' and 'Cyber Security Leadership and Governance' as the same governance domain that anchors board and senior-management accountability. The Framework places ultimate responsibility for cyber security on the Board of Directors and requires that responsibilities be defined throughout the organization. Conclude that governance obligations sit at the top of the control hierarchy, so audits should trace whether board-level intent, roles and responsibilities are documented before evaluating downstream technical controls.
- **Grounding — this node (Page 15 / 3.1.4 Principle):** "Responsibilities to implement, maintain, support and promote cyber security should be defined throughout the Member Organization."
- **Grounding — related node (Page 15 / 3.1.4):** "The Board of Directors has the ultimate responsibility for cyber security"

### [[Cyber Security Policy]] — `references` [EXTRACTED]
- **What this link tells you:** When evaluating governance compliance, treat the Cyber Security Policy as the required output of the leadership-and-governance domain: the board must set the intent and the CISO must develop and maintain the policy. The Framework specifies mandatory policy contents (definition of cyber security, objectives and scope, statement of board intent, defined responsibilities, references to supporting standards, and requirements covering classification, risk assessment, breach reporting and BCM). Conclude that a governance review should verify the policy exists, is board-endorsed and CISO-maintained, and contains every enumerated element, since gaps here undermine all subordinate standards and procedures.
- **Grounding — this node (Page 16 / 3.1.4):** "The CISO should be responsible for: a. developing and maintaining: ... 2. cyber security policy;"
- **Grounding — related node (Page 15 / 4):** "The cyber security policy should include: a. a definition of cyber security; ... c. a statement of the board's intent"

### [[Cyber Security Roles and Responsibilities]] — `references` [EXTRACTED]
- **What this link tells you:** When mapping accountability under the SAMA Cyber Security Framework, treat Roles and Responsibilities (3.1.4) as a mandatory component of the broader Leadership and Governance domain, not a standalone item. The governance requirement that the cyber security policy define 'general and specific responsibilities for cyber security' is operationalised by 3.1.4, which fixes ultimate responsibility on the Board and cascades duties to senior management and the CISO. A compliance reviewer should conclude that gaps in defined roles are governance-domain deficiencies affecting the Member Organization's maturity rating, and should check that board-level accountability is documented, not just delegated.
- **Grounding — this node (Page 15 / 3.1.4):** "a definition of general and specific responsibilities for cyber security"
- **Grounding — related node (Page 15 / 3.1.4):** "The Board of Directors has the ultimate responsibility for cyber security"

### [[Cyber Security Strategy]] — `references` [EXTRACTED]
- **What this link tells you:** When assessing governance obligations, read the Cyber Security Strategy as a governance-domain deliverable owned at defined levels, not a free-floating planning exercise. The framework requires the cyber security policy to state the board's intent and overall objectives, while the CISO is expressly made responsible for 'developing and maintaining' the cyber security strategy — linking strategy directly to the leadership/governance structure. A reviewer should verify that the strategy exists, aligns with board-approved objectives, and has a documented CISO owner, and should treat absence of these as a governance-domain finding.
- **Grounding — this node (Page 15 / 3.1.3):** "a statement of the board's intent, supporting the cyber security objectives"
- **Grounding — related node (Page 16 / 3.1.2):** "The CISO should be responsible for: a. developing and maintaining: 1. cyber security strategy"

### [[SAMA Cyber Security Framework]] — `references` [EXTRACTED]
- **What this link tells you:** When mapping accountability for cyber security in a SAMA Member Organization, start from the Framework's governance domain because it fixes where ultimate responsibility sits — the Board of Directors — and requires the cyber security policy to define general and specific responsibilities. This is a defining/structural link: 'Leadership and Governance' is the Framework subdomain that assigns board intent, roles, and senior-management/CISO duties. Conclude that governance obligations (board sign-off, defined roles, policy content) are directly assessable Framework requirements you can hold the entity to, not aspirational best practice.
- **Grounding — this node (Page 15, §3.1.4 Cyber Security Roles and Responsibilities):** "Responsibilities to implement, maintain, support and promote cyber security should be defined throughout the Member Organization"
- **Grounding — related node (Page 15, §3.1.4):** "The Board of Directors has the ultimate responsibility for cyber security"
