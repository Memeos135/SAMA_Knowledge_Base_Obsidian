# IT Governance Maturity Model

## Connections

### [[Information Technology Governance Framework]] — `references` [EXTRACTED]
- **What this link tells you:** When judging whether a Member Organization is 'compliant' with the Framework, note that compliance is not binary but graded against the six-level maturity model (0–5), and that levels 3–5 require first meeting all criteria of preceding levels. SAMA reviews and audits the periodic self-assessment 'to determine the level of compliance with the framework and the IT maturity level'. For a compliance decision, conclude that partial or ad-hoc implementation still maps to a defined (low) maturity score, and that a target maturity level set by SAMA — not mere existence of controls — is the benchmark to satisfy.
- **Grounding — this node (Page 9):** "In order to achieve levels 3, 4 or 5, Member Organizations should first meet all criteria of the preceding maturity levels."
- **Grounding — related node (Page 6):** "To achieve an appropriate maturity level of IT controls within the Member Organizations."
