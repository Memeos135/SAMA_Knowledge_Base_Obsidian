# Forbearance

## Connections

### [[Restructuring]] — `references` [EXTRACTED]
- **What this link tells you:** When assessing any modification of a credit contract, start from the Restructuring provision, because it defines forbearance as one of only two possible outcomes of restructuring — the other being renegotiation/refinancing/rescheduling — and the classification turns on whether the modified terms are concessionary and driven by the borrower's financial difficulty. Both nodes are in Section 7 of the same SAMA Rules, so a modification only qualifies as forbearance (with its Stage 2B/3A/3B reporting and cure consequences) when financial difficulty coexists; absent difficulty and value reduction it is mere renegotiation. A reviewer should therefore verify the financial-difficulty determination first, as it is the pivot that decides which restructuring branch — and which stage treatment — applies.
- **Grounding — this node (Page 17 / Section 7.1.1):** "The finance company grants a concession that it would not otherwise consider... A concession is granted only when the borrower is experiencing financial difficulty."
- **Grounding — related node (Page 17 / Section 7):** "Restructuring may only occur in the form of either forbearance or renegotiation and/or refinancing and/or rescheduling."

### [[Stage 123 Exposure Classification|Stage 1/2/3 Exposure Classification]] — `conceptually_related_to` [EXTRACTED]
- **What this link tells you:** When deciding how a concession affects an exposure's regulatory reporting, note that forbearance is not stage-neutral: the Rules require that forborne exposures 'should only be reported in Stage 2B, 3A or 3B,' directly constraining the staging outcome. Both concepts live in the same SAMA Rules, so identifying a concession granted due to borrower financial difficulty removes the option of Stage 1 or Stage 2A treatment and triggers the specific cure/probation periods for re-staging forborne exposures. A reviewer should check that any exposure flagged as forborne is not sitting in a prohibited stage and that re-staging respects the 12-month probation (restart on re-default) applicable to forborne accounts.
- **Grounding — this node (Page 17 / Section 7.1.1):** "For regulatory classification purposes, these exposures should only be reported in Stage 2B, 3A or 3B."
- **Grounding — related node (Page 14):** "If a forborne exposure becomes non-performing during the 12-month probation/cure period, the probation/cure period starts again."
