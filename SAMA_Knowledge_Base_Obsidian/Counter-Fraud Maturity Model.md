# Counter-Fraud Maturity Model

## Connections

### [[Counter-Fraud Framework]] — `references` [EXTRACTED]
- **What this link tells you:** When assessing whether a Member Organisation is compliant with the SAMA Counter-Fraud Framework, don't treat control existence as a pass/fail — the Framework measures compliance against the Counter-Fraud Maturity Model, which grades six cumulative levels (0–5) and requires all criteria of preceding levels before a higher level can be claimed. The Framework defines the model as its measurement instrument, so a supervisory self-assessment answer is only meaningful when expressed as a maturity level. You would conclude that reaching levels 3+ (formalised, embedded controls) is the practical compliance benchmark, and that partial or informal controls score at level 1–2 regardless of good intentions.
