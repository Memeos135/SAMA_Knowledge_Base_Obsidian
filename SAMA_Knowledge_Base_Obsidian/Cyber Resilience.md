# Cyber Resilience

## Connections

### [[Business Continuity Management Framework]] — `references` [EXTRACTED]
- **What this link tells you:** When determining the boundaries of the BCM framework's obligations, note that cyber resilience is included as a component (section 2.7) but the framework explicitly cross-refers threat/vulnerability management to the separate SAMA Cyber Security Framework. This means continuity obligations and cyber-control obligations overlap but are governed by two instruments; the framework also requires BCP test scenarios to consider cyber security scenarios. A reviewer should conclude that cyber-related resilience must be assessed against both this framework and the Cyber Security Framework, and should not treat the BCM framework alone as covering the full cyber control set.

- **Grounding — related node (Page 12):** "For more control considerations to improve the overall resilience, e.g., threat management, vulnerability management, please refer to the SAMA - Cyber Security Framework."

### [[SAMA Cyber Security Framework (referenced)]] — `cites` [EXTRACTED]
- **What this link tells you:** When implementing the BCM Framework's IT DRP and Cyber Resilience controls, read the express cross-reference to the SAMA Cyber Security Framework as directing you to that separate document for the detailed cyber controls (threat and vulnerability management) not fully specified here. The BCM note states 'please refer to the SAMA - Cyber Security Framework' for further resilience control considerations, confirming the two frameworks are meant to be applied together. You should conclude that cyber-resilience compliance under BCM is not self-contained — the CSF supplies the operative cyber control detail.
