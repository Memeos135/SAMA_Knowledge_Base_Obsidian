# Cash Transport System Recommendations

## Connections

### [[Security-Inked Damaged Cash Compensation Mechanism]] — `references` [INFERRED]
- **What this link tells you:** If you are scoping obligations for banks and cash-in-transit companies, treat these as two connected but separately-sourced instruction sets in the currency/cash-handling regime rather than one continuous rule. The 5630 circular sets security recommendations for the cash-transport activity (armoured-vehicle crewing, ATM-feeding separation, high-spec traceable/self-destruct containers, SIMAH credit checks on staff), while 5838 governs the downstream consequence — how currency stained by security ink is compensated — and expressly builds on the earlier SAMA circular mandating use of security containers by cash-transport firms, banks and money changers. The connection appears real (both concern secured cash movement and the self-inking containers 5630 recommends), but 5838 references its own predecessor circular rather than 5630 by number, so verify which circular actually imposes the container mandate before relying on the chain.
- **Grounding — this node (Page 1–2):** "adopting the use of high-specification cash-transport containers ... allowing tracking and self-destruction of cash if the planned route changes (paraphrase)"
- **Grounding — related node (Page 1 / item 1):** "obligation of cash-transport companies, banks and money changers to use security containers for cash transport upon receipt and delivery (paraphrase)"
- **Caveat:** INFERRED; both documents' Arabic is OCR-garbled and 5838 cites a predecessor circular by number, not 5630. Confirm the exact instrument imposing the container mandate.
