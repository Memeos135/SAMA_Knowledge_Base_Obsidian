# Secure Disposal

## Connections

### [[Secure Erase]] — `references` [EXTRACTED]
- **What this link tells you:** When determining what counts as compliant 'secure disposal of information assets' under section 3.3.11, treat 'secure erase' as one of the technical methods the disposal standard must specify: the glossary defines secure erase as a firmware-based overwrite of a hard drive (with 'secure wiping' pointing to the same term). The link matters because the disposal obligation also extends to third-party providers used for disposal, transport and storage, who must comply with the same standard. You would conclude that an acceptable disposal standard needs a defined erasure method for reusable media, not merely physical destruction, and that this expectation flows through to outsourced disposal arrangements.
- **Grounding — this node (Page 31 / 3.3.11 item 6):** "third party service providers used for secure disposal, transport and storage comply with the secure disposal standard and procedure"
- **Grounding — related node (Page 55 / Glossary):** "Secure erase An overwrite technology using a firmware-based process to overwrite a hard drive."
