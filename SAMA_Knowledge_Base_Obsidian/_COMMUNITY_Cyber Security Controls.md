# Cyber Security Controls

**Cohesion:** 1.00 - tightly connected
**Members:** 2 nodes

## Why this community

Information/cyber security control obligations for supervised entities, spanning general cyber-security controls and the more specific data-focused cybersecurity controls framework (DCC-1:2022). Part of the governance/risk and operational-resilience regime.

## How members connect

- The Cyber Security Controls Circular sets the baseline institution-wide security obligations; DCC-1:2022 layers additional data-classification and data-protection controls on top.
- Linked as conceptually related — DCC-1 should be read as complementary/more granular to the general controls, not as a replacement.
- Compliance decisions must treat both as concurrently applicable minimum standards where each is in scope for the entity.
