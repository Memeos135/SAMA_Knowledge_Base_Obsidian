# Treatment for Shariah

## Connections

### [[Liquidity Coverage Ratio]] — `references` [EXTRACTED]
- **What this link tells you:** When scoping LCR obligations for a Shari'ah-compliant bank, read the Shari'ah treatment as a conditional carve-out within the same LCR standard rather than a separate lighter regime. The provision lets national supervisors define Shari'ah-compliant products (e.g. Sukuk) as alternative HQLA for these banks only, subject to conditions/haircuts, but expressly states the resulting minimum LCR standard 'should not be lower than' that applicable to other banks. Note also that SAMA records it 'has not utilized any of the options under the alternate treatment,' so before relying on any Sukuk-as-HQLA position you should confirm current SAMA practice rather than assume the discretion has been exercised.
- **Grounding — this node (Page 24 / para 68):** "minimum LCR standard, calculated based on alternative HQLA (post-haircut) ... should not be lower than the minimum LCR standard applicable to other banks"
- **Grounding — related node (Page 18 / para 52(a)):** "Note: SAMA does not utilize Level 2B assets for the purpose of LCR computation, currently"
