# SAMA Circular on Amended LCR Prudential Returns

## Connections

### [[Guidance Manual for the Returns Management System]] — `conceptually_related_to` [INFERRED]
- **What this link tells you:** When determining how a bank actually files its Amended LCR prudential returns, treat this as a lead rather than an established rule: the LCR circular sets the substantive obligation to submit prudential returns on defined deadlines, while the RMS manual describes the portal mechanism SAMA uses for submitting returns generally. Both concern 'prudential returns,' so the RMS process may be the current channel for the LCR filings, but the circular pre-dates the manual (2013 vs 2022) and does not itself reference RMS. Confirm from a current SAMA instruction whether LCR returns must now be filed through RMS before relying on the manual's steps for that obligation.

### [[SAMA Circular on Revised Amended LCR Regulations]] — `references` [EXTRACTED]
- **What this link tells you:** If you are identifying the operative LCR return requirements for banks, note that the later 2014 circular expressly supersedes/revises the 2013 circular's Amended LCR package, so you should not rely on the 2013 guidance documents (General Guidance, Specific Guidance, Prudential Return, FAQs, National Discretions) as current. The 2014 circular refers back to circular #341000107020 and issues a 'revised package' addressing gaps against BCBS Basel III standards. For compliance decisions, use the revised documents attached to the 2014 circular and treat the 2013 versions as historical unless a provision was carried forward unchanged.
