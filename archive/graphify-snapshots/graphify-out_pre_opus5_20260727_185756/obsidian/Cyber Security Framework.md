# Cyber Security Framework

## Connections

### [[Authentication Standard]] — `references` [EXTRACTED]
- **Why:** The Counter-Fraud Framework's Authentication Standard explicitly mandates that Member Organisations consult specific controls within SAMA's Cyber Security Framework (sections 3.3.5 and 3.3.13) when defining authentication requirements, creating a direct normative cross-reference between the two instruments. This is a structural dependency: the Counter-Fraud Framework defers to the Cyber Security Framework for the technical identity/access and electronic banking controls that underpin fraud-resistant authentication.
- **This node (Page 7 / Section 1.3 Scope):** "The Framework should be implemented in conjunction with other SAMA frameworks, in particular SAMA's Cyber Security Framework ('The Cyber Security Framework'), which should be referred to for specific Cyber Security related requirements."
- **Related node (Page 37 / Section 4.4 Authentication, Control Requirement d):** "When defining the authentication standard, Member Organisations should take note of the following Control Requirements outlined in The Cyber Security Framework: 1. 3.3.5 Identity and access management 2. 3.3.13 Electronic Banking Services"
- **Implication:** A Member Organisation's authentication standard must demonstrably map its design decisions to Cyber Security Framework controls 3.3.5 and 3.3.13, requiring a documented cross-reference traceability matrix auditable by SAMA examiners across both the Counter-Fraud Department and Cyber Security Team sign-off records.
